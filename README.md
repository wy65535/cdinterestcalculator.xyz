# CD Interest Calculator

Free online Certificate of Deposit (CD) interest calculator with compound interest calculations, APY comparisons, and CD ladder planning tools.

**Live Site:** https://cdinterestcalculator.xyz

## Features

- Comprehensive CD interest calculations with compound interest
- Support for multiple compounding frequencies (daily, monthly, quarterly, annually)
- Early withdrawal penalty calculator
- CD comparison tool for multiple options
- Interactive charts and detailed breakdowns
- Responsive design for all devices
- SEO optimized

## Deployment

### Cloudflare Pages

1. Push this repository to GitHub
2. Connect your GitHub repository to Cloudflare Pages
3. Configure build settings:
   - Build command: (none needed - static site)
   - Build output directory: /
4. Deploy

### GitHub Pages

Alternatively, you can deploy using GitHub Pages:
1. Go to repository Settings > Pages
2. Select main branch as source
3. Save

## Google AdSense Setup

1. Apply for Google AdSense
2. Update `ads.txt` with your publisher ID
3. Add AdSense code to HTML files after approval
